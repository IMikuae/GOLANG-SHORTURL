API Access

Integrasikan Yue Short ke proyek kamu lewat REST API.

API Key

{{template "icon" dict "n" "o-exclamation-triangle" "c" "h-3.5 w-3.5 shrink-0 text-amber-400"}}Jangan bagikan API key di kode publik. Simpan sebagai environment variable di sisi server.

{{template "icon" dict "n" "o-code-bracket" "c" "h-4 w-4 text-indigo-400"}}Endpoint

Buat tautan pendek

POST /api/shorten
Content-Type: application/json
Authorization: Bearer <API_KEY>

{ "url": "https://example.com/very/long", "alias": "docs" }

Respons sukses (201)

{
  "shortUrl": "{{.Origin}}/docs",
  "shortCode": "docs"
}

Contoh dengan cURL

curl -X POST {{.Origin}}/api/shorten \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <API_KEY>" \
  -d '{"url":"https://example.com"}'

alias (opsional) — slug kustom, huruf/angka/tanda hubung, maks 32 karakter.

password (opsional) — minimal 4 karakter, tautan jadi terproteksi.

expiresAt (opsional) — format YYYY-MM-DD, tidak boleh masa lalu.

domainId (opsional) — ID custom domain milikmu yang sudah terverifikasi (lihat GET /api/domains). Harus memakai header Authorization / sesi; tanpa itu ditolak.

Tujuan yang menunjuk ke jaringan internal (localhost, 10.x, 172.16-31.x, 192.168.x, 169.254.x, 127.x, alamat IPv6 privat) selalu ditolak, dalam bentuk IPv4/IPv6/desimal/oktal/heksadesimal sekalipun.

Tanpa header Authorization, tautan tetap bisa dibuat tetapi tidak terhubung ke akun manapun.
